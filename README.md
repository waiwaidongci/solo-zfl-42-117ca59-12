# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

已实现闭环：
- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付。
- 今日待阴干、缺陷作品、最近交付三类列表。
- 可更新状态、记录断线/翘线、查看作品详情。
- 支持筛选、交付排序、localStorage 持久化和 JSON 导出。

借展与外借归还台账：
- 借展单可包含多件作品；申请人、审批人、承运人、验收人四角色须为不同人员，各步操作须由对应角色本人执行。
- 同一作品不能同时出现在两张未结束借展单（申请中/已批准/已出库/归还待验）。
- 流转：申请 → 批准 → 整批出库 → 整批归还（归还待验）→ 验收关闭；驳回、撤回、逾期、损坏理赔均强制留原因。
- 出库要求每件作品为「待交付」且无未处理缺陷；归还要逐件确认到齐。任一作品不符条件则整批不放行，不产生部分变更。
- 关闭后原记录只读，补充说明以追加记录呈现。
- 旧作品无需重建即可纳入借展；导出为作品+借展单整体备份，导入恢复（兼容旧版纯作品数组）后关联与历史一致。
- 多页面同时使用安全：所有变更在跨标签互斥锁（Web Locks，无则回退 localStorage 令牌锁）保护的临界区内完成"同步快照 → 校验 → 生效"，两个页面同时给同一作品建单时只有一个成功，结果不受调度顺序影响；失败方收到明确冲突提示；其他页面提交后本页自动刷新。
- 导入前完整校验备份格式（作品 id、借展单状态、作品列表、流转/理赔/补充记录等），任何格式问题都会说明失败原因且保持现有作品与借展记录不变。
